# Остатки наборов

Одностраничное веб‑приложение для просмотра остатков проб/тестов по клиентам и наборам.
Всё приложение — это **один файл `index.html`** (библиотека для чтения Excel встроена прямо
в него), никакого сервера, установки или других файлов рядом не требуется.

## Как это работает

**Рекомендуемый формат — `shablon-ostatki.xlsx`** (лежит в этом репозитории). Простая таблица,
одна строка = один клиент + один набор + текущий остаток:

| Филиал   | Клиент         | Набор | Остаток |
|----------|----------------|-------|---------|
| Москва   | ООО Ромашка    | PRRS  | 120     |
| Белгород | Агро-Белогорье | PRRS  | 300     |

- **Филиал** — «Москва» или «Белгород» (ровно так, без опечаток). Можно оставить пустым — тогда
  при загрузке приложение один раз спросит, к какому филиалу отнести весь файл.
- Один файл может содержать сразу оба филиала и сколько угодно клиентов/наборов.
- Столбец «Остаток» — то число, которое должно показаться в приложении.

Помимо этого, приложение по‑прежнему понимает и старые форматы лаборантов (файл на клиента
с датами операций, журнал проведённых исследований и т.п.) — они распознаются автоматически.
Если структура файла не распознана вообще — появится окошко, где можно вручную указать имя
клиента и нужные столбцы.

Данные сохраняются в браузере телефона (localStorage), поэтому при повторном открытии
ничего заново загружать не нужно — только когда появится обновлённый файл. Можно загружать
сразу несколько файлов за раз. Название клиента можно поправить (✎), а филиал — переключить,
тапнув на бейдж рядом с именем.

## Как открыть на телефоне

**Через ссылку (надёжнее всего):** разместите `index.html` на GitHub Pages или любом другом
статическом хостинге и откройте ссылку в браузере телефона, добавив её на главный экран.
Учтите: GitHub Pages на бесплатном тарифе работает только для **публичных** репозиториев —
для приватного репозитория либо сделайте его публичным, либо заведите отдельный публичный
репозиторий только для этого приложения.

**Локально (без хостинга):** можно просто переслать себе файл `index.html` и открыть его в
браузере телефона. Важно открыть именно **в браузере** (например, через «Поделиться» →
Safari/Chrome, или через меню браузера «Открыть файл»), а не через «Быстрый просмотр» в
приложении «Файлы» — режим предпросмотра не выполняет JavaScript и приложение не заработает.

## Файлы в репозитории

Приложение «Остатки»:

- `index.html` — само приложение (один файл).
- `shablon-ostatki.xlsx` — шаблон для загрузки остатков (см. выше).
- `sample-data.csv` — ещё один пример структуры (старый плоский формат) для проверки приложения.
- `THIRD_PARTY_LICENSES.txt` — лицензия библиотеки SheetJS, встроенной в `index.html`.

Приложение «Второй мозг»:

- `diary/` — собранная веб-версия (обновляется автоматически при сборке).
- `diary/sync-setup.html` — страница с инструкцией и скриптом для Google Таблицы.

Служебное:

- `.nojekyll` — отключает обработку файлов на GitHub Pages, чтобы они
  раздавались как есть.
