Синхронизация дневника с Google Таблицей

Один раз настроив её, вы получите: автоматическую выгрузку всех записей в таблицу и возможность закидывать задачи из своего Excel прямо в приложение.

Шаг 1. Создайте таблицу

  1. Откройте sheets.new (лучше с компьютера — так удобнее).
  2. Назовите таблицу, например, «Мой дневник».

Шаг 2. Вставьте скрипт

  1. В таблице: меню Расширения → Apps Script.
  2. Удалите всё в открывшемся редакторе и вставьте код ниже (кнопка «Скопировать»).
  3. Нажмите значок дискеты (Сохранить).

Шаг 3. Опубликуйте скрипт

  1. Справа вверху нажмите Развернуть → Новое развёртывание.
  2. Значок шестерёнки → выберите тип Веб-приложение.
  3. «Выполнять от имени» — От моего имени.
  4. «У кого есть доступ» — Все. (Это обязательно, иначе приложение не сможет обращаться к таблице.)
  5. Нажмите Начать развёртывание, разрешите доступ своему аккаунту (Google предупредит, что приложение не проверено — нажмите «Дополнительные настройки» → «Перейти»). Это ваш собственный скрипт, он имеет доступ только к этой таблице.
  6. Скопируйте URL веб-приложения (заканчивается на /exec).

Шаг 4. Подключите в приложении

  1. В дневнике: вкладка Профиль → Подключить таблицу.
  2. Вставьте скопированную ссылку → «Подключить».
  3. Приложение сразу выполнит первую синхронизацию — в таблице появится лист «Записи» со всеми вашими записями.

Как перенести задачи из вашего Excel

  1. Откройте в таблице лист «Входящие».
  2. Вставьте задачи одним из двух способов:
    — просто список: тексты задач в столбец A, по одной на строку;
    — рабочая таблица целиком, вместе с шапкой «Задачи | Ответственный | Статус | Срок | Примечание» — скрипт сам её распознает: строки со статусом «выполнено» пропустит, а срок, ответственного и примечание допишет в текст задачи.
  3. В приложении: Профиль → Синхронизировать сейчас.
  4. Задачи появятся в телефоне (фильтр «Задачи»), а из «Входящих» переедут в лист «Импортировано».

Личный дневник

В приложении есть переключатель «Работа / Личное». Личные записи (мысли, идеи, записи дня) не смешиваются с рабочими и выгружаются на отдельный лист «Личное» — он создастся сам при первой синхронизации. Лист «Записи» остаётся только для рабочего.

Реестр закупок

После обновления скрипта и первой синхронизации в таблице появится лист «Закупки». Скопируйте туда строки своего рабочего Excel-реестра — столбцы те же: Оплата, Сумма, Поставщик, Сроки, Ориентировочные даты, Отдел, Место доставки, Наименование, Тендер, (пусто), ЭДО, Закрывающие. Вставляйте начиная со строки 2 (под шапкой).

При каждой синхронизации скрипт сам: раздаёт закупкам номера (столбец id), проставляет статус «в работе», красит строки — жёлтым в работе, зелёным закрытые. Статус можно менять и в таблице (написать «закрыта» в столбце «Статус»), и с телефона — вкладка «Закупки» → карточка → «Отметить закрытой».

Почта → задачи

Переслали письмо на свой же адрес с пометкой +zadachi — оно стало задачей в дневнике. Настройка один раз, три действия.

Куда пересылать

К вашему адресу перед «собакой» добавляется +zadachi. Это не новый ящик — письмо придёт в вашу же почту, просто скрипт его узнает:

ivanova+zadachi@gmail.com
Вместо ivanova — ваше имя ящика. Точный адрес скрипт скажет сам на шаге 3, гадать не нужно.

Что сделать

  1. Вставьте в редактор Apps Script свежий код с этой страницы (кнопка «Скопировать» выше) и сохраните — значок дискеты.
  2. Нажмите Развернуть → Управление развёртываниями → карандаш (изменить) → «Версия» → Новая версия → Развернуть. Без этого шага таблица останется на старом коде.

Всё. Никакие функции запускать не нужно — почта проверяется сама при каждой синхронизации.

Как пользоваться

  1. Пересылаете письмо на свой адрес с +zadachi.
  2. В дневнике: Профиль → «Синхронизировать сейчас».
  3. Письмо появилось в списке задач. Тема письма стала задачей, к ней добавлено начало текста и ссылка на само письмо.

Если задача не появилась

Откройте свою ссылку Web App, дописав в конец ?mail=1:

https://script.google.com/…/exec?mail=1

Скрипт проверит почту прямо сейчас и ответит обычным текстом: на какой адрес пересылать, сколько писем нашлось и сколько задач добавилось. Редактор скриптов открывать не нужно.

По желанию: если хотите, чтобы письма забирались сами каждые 10 минут, даже без синхронизации, — в редакторе Apps Script выберите в списке функций setupMail и нажмите «Выполнить». Это необязательно.

Обработанные письма запоминаются в новом листе «Письма» по номеру письма. Ярлыки Gmail больше не используются — раньше именно из-за них задачи и не приходили. Если захотите, чтобы письмо обработалось заново, удалите его строку из листа «Письма».

Важно: лист «Записи» приложение переписывает целиком при каждой синхронизации — не редактируйте его вручную, правки затрутся. Всё новое добавляйте через лист «Входящие» или через само приложение. Ссылка Web App — секретная: любой, у кого она есть, сможет читать и менять эту таблицу. Никому её не передавайте.
