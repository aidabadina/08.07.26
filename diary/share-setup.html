Письма и заметки в дневник одним касанием

Настраивается один раз, минут за пять. После этого из любого приложения на iPhone — почты, Safari, мессенджера — выделенный текст попадает в дневник через кнопку «Поделиться». Google-скрипт для этого не нужен: текст идёт напрямую в приложение.

Шаг 1. Создайте быструю команду

  1. Откройте приложение «Быстрые команды» (оно есть на каждом iPhone).
  2. Вкладка «Мои команды» → знак + вверху справа.
  3. Нажмите «Добавить действие» → в поиске наберите URL → выберите действие «URL».
  4. В поле URL вставьте эту строку целиком:
https://aidabadina.github.io/08.07.26/diary/?type=task&add=
  1. Сразу после add= (в конце строки, без пробела) нужно подставить текст. Для этого нажмите на поле URL и в панели над клавиатурой выберите переменную «Вход быстрой команды» (Shortcut Input). Она встанет в конец ссылки.
  2. Добавьте второе действие: «Открыть URL» (поиск: открыть URL).

Шаг 2. Включите кнопку «Поделиться»

  1. Вверху экрана команды нажмите значок ⓘ (или «Настройки команды»).
  2. Включите переключатель «Показывать в меню «Поделиться»».
  3. Назовите команду, например «В дневник», и нажмите «Готово».

Как пользоваться

  • Письмо из почты: откройте письмо → кнопка «Поделиться» → пролистайте вниз до «В дневник» → готово, задача в дневнике.
  • Кусок текста откуда угодно: выделите текст → «Поделиться» → «В дневник».
  • Ссылка на статью: в Safari «Поделиться» → «В дневник».

Дневник откроется сам, внизу мелькнёт «Задача добавлена» — и запись уже в списке. Если у вас настроена Google Таблица, она уедет туда при ближайшей синхронизации.

Хотите вторую команду — для личных заметок?

Повторите те же шаги, но вставьте другую ссылку и назовите команду «В личный дневник»:

https://aidabadina.github.io/08.07.26/diary/?type=note&sphere=personal&add=

Разница только в конце: type=task — задача в раздел «Работа», type=note&sphere=personal — запись в «Личное».

Если текст очень длинный (несколько экранов), браузер может его обрезать — в дневник попадёт начало. Для длинных писем надёжнее пересылка на почту +zadachi, она никакого ограничения не имеет. Обычные письма и заметки проходят целиком.
